# UkayLoop project notes

- `src/main.tsx` owns client routing and marketplace session state. `src/market.tsx` contains public storefront and product discovery; `src/account.tsx` contains Identity and checkout. The seller and admin workspaces are lazy-loaded from `src/workspace.tsx`, with editors in `src/workspace-forms.tsx`.
- `src/styles.css` contains responsive design tokens and shared components. Keep changes consistent with the teal marketplace, using the existing `Link`, `Modal`, `Pill`, and `Asset` helpers. `Asset` delivers generated catalog imagery from `public/img/` through the Netlify Image CDN with a static fallback.
- `shared/catalog.mjs` contains read-only sample data used by both the storefront and the checkout API. `src/workspace-data.ts` contains isolated workspace fixtures. Demo edits, favorites, and anonymous bag state are temporary and do not affect the live data set.
- `netlify/server/index.mjs` is the request-driven API. Keep authenticated operations ownership-scoped and keep the admin role check server-side. The public catalog must never serialize seller-only fields or include unlisted, suspended, or expired shops. Netlify Blobs stores binary assets; `db/schema.ts` is the source of truth for Postgres schema changes, with generated migrations under `netlify/database/migrations/`.
- Store listing prices and recorded costs as whole Philippine pesos. Financial totals use completed offline sales in live workspaces, snapshot sale price and cost, and subtract separate recorded expenses. Test checkout orders never reduce stock or count toward actual revenue. Tithes settings are private and never included in catalog or admin responses.
- Keep payments and renewals clearly marked as simulated unless a verified integration exists. Do not add automatic deletion without an implemented retention, warning delivery, and recovery process.
